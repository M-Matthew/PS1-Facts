# PS1-Facts
This app let you interactively know some of the most curious facts on the first PlayStation.

## Description
On the 15.08.2026 I could upload the second Android app I have ever made. This app as an original initial animation, a background image and some buttons. These buttons represent a selected PS1 fact, which will be displayed through an image on the top screen and a description on the center. The sound in the background will change randomly. You wll also hear a particular sound by clicking on each button. Can you recognize that sound?
